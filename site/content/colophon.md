This site uses [Hugo] and the [congo] theme, hosted on [Cloudflare Workers].

Changes are built and published automatically with a [GitHub Action].

There is also an [RSS feed](https://jnsgr.uk/index.xml) for this site.

I wrote about the original implementation in my [first blog
post](https://jnsgr.uk/2024/01/building-a-blog-with-go-nix-hugo/).
